First of all, thank you for considering contributing to FiveM Hot Reload !

## Development Process

1. Fork the repository
2. Make your changes
3. Make a pull request (example: `feat: add <feature name>`)

## Useful commands for development
```bash
cargo run --bin hot-reload-build
```
This command allows you to build the project and test it for production.
You can choose what you want to build (UI, Watcher, FXServer) and on which platform (Windows, Linux, MacOS).
