Tout d'abord, merci d'envisager de contribuer à FiveM Hot Reload !

## Processus de Développement

1. Fork le repository
2. Faite vos modifications
3. Faites un pull request (exemple: `feat: add <nom de la fonctionnalité>`)

## Commandes utiles pour le développement
```bash
cargo run --bin hot-reload-build
```
Cette commande vous permet de build le projet et le tester pour la production.
Celle vous permet de choisir ce que vous voulez build (UI, Watcher, FXServer) et sur quelle plateforme (Windows, Linux, MacOS).
